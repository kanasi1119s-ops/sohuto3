# LP草稿: オフライン請求書メーカー

**キャッチコピー案**
1. 請求書のデータ、クラウドに置かなくていい。
2. ネットがなくても作れる。月額もかからない（買い切り想定）。
3. インボイス形式の請求書を、ブラウザだけで。

## 特長（実装・確認済みのもののみ）
- データは端末のブラウザ内にのみ保存。外部送信なし
- 初回読込後はオフラインで起動
- 税率ごと（10% / 軽減8%）の消費税を、1請求書につき税率ごとに1回端数処理
- 源泉徴収税額の自動計算（任意）
- JSONバックアップ・復元 / CSV出力 / 印刷・PDF保存
- 登録番号（T+13桁）の形式チェック

## 料金プラン案（仮説・要検討）
- 買い切り 1,980〜2,980円（1ライセンス=1ユーザーの業務利用）※価格は市場検証で決定

## 注意書き
- 税務判断は保証しません。記載事項の確認は利用者・税理士等が行ってください
- データはブラウザ内保存のため、バックアップ取得を推奨します
