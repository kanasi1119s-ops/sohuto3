# 商品説明文（BOOTH / Gumroad 用案）
**オフライン請求書メーカー**は、インボイス形式の請求書を作成できるブラウザアプリです。データは端末のブラウザ内にのみ保存され、外部へ送信されません。ネットワークがない環境でも、初回読み込み後は利用できます。

【できること】請求書の作成・保存・再編集／10%・軽減8%の税率別計算／源泉徴収の計算／JSONバックアップ／CSV出力／印刷・PDF保存
【動作環境】最新の Chrome / Edge / Firefox / Safari
【ご注意】会計・税務上の正確性を保証するものではありません。ご利用前に内容をご確認ください。ZIP を展開し、付属の手順で静的ホスティングまたはローカルサーバーで開いてください。
