# 訴求文（草案）
**キャッチ**: 請求書の消費税、税率ごとに1回の端数処理でサッと計算。
**LP**: CSVを渡すだけ。10%/8%を自動集計し、端数処理（切捨/四捨五入/切上）を選べます。オフライン動作・外部通信なし・依存パッケージなし。
**機能**: 税率別集計 / 端数処理3種 / JSON出力 / 異常入力をエラー表示
**料金案**: 買い切り（価格は人間が決定）。※税務助言ではありません。
## 商品説明（BOOTH/Gumroad用）
オフラインで動くインボイス税額計算CLI。Node.js 18以上が必要です。データは端末から出ません。サポート範囲: CSV入力のみ（PDF出力・値引行は未対応）。
