# 商品説明文(BOOTH/Gumroad用案)
**領収書ネーマー — ファイルが端末から出ない、領収書・請求書のリネームツール**

PDFや画像の領収書・請求書に「取引日_取引先_金額_種別」の名前を付けて、検索簿CSVと一緒にZIPで書き出します。ブラウザで動くので、インストール不要。入力した情報やファイルは外部に送信されません(ネット接続なしでも動作します)。

【できること】規則的なリネーム/重複の自動連番/検索簿CSV出力/バックアップZIPの書き出し・復元
【できないこと】OCRによる自動入力、法令適合の保証、クラウド同期
【動作環境】最新のChrome/Edge/Firefox/Safari(IndexedDB対応ブラウザ)
【ご注意】本ツールは電子帳簿保存法への適合を保証しません。ブラウザのデータ消去で保存内容が消えるため、ZIPバックアップをお取りください。
