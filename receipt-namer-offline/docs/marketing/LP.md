# LP草稿
**キャッチコピー案**
1. 「領収書のファイル名、日付・取引先・金額で揃えませんか。」
2. 「ファイルは端末から出ません。だから、安心して整理できる。」
3. 「ZIP一つで、リネーム済みファイルと検索簿CSV。」

## 特長(すべて実装・検証済み)
- **取引日_取引先_金額_種別** の規則で自動リネーム(重複は連番)
- 検索簿CSV(Excel対応)も同時に書き出し
- **外部通信なし**: ブラウザのCSPで通信を禁止。ネットを切っても動作(E2Eで検証)
- 全角数字・カンマ・「円」付きの金額もOK
- バックアップZIPから復元可能
- サブスクなし(買い切り想定)

## 料金プラン案(仮説・要人間判断)
- 買い切り 1,480円〜2,980円 / 個人事業主・小規模事業者向け ※価格は市場検証の仮説であり、成果を保証するものではありません

## 注意書き(必ず掲載)
電子帳簿保存法の要件充足を保証するものではありません。OCRによる自動読み取りは行いません。データはブラウザ内に保存されるため、定期的なZIP書き出しを推奨します。
