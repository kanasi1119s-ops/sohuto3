# オフライン見積・請求書メーカー (offline-invoice-maker)

ブラウザだけで完結する、見積書・請求書の作成ツールです。データはすべて端末内（IndexedDB）に保存され、
サーバーには一切送信されません。ネットワークを切断した状態でも動作します。

## 配布形態

**L1: ブラウザ完結Webアプリ（静的SPA）**

- サーバー不要。ビルドした `dist/` を丸ごとZIP配布するか、静的ホスティング（GitHub Pages等）にそのまま置くだけで動きます。
- データは各利用者のブラウザの IndexedDB にのみ保存されます。複数端末間の同期機能はありません（意図的に持たせていません）。

## 主な機能（MVPスコープ）

- 顧客の登録・一覧・削除
- 見積書・請求書の作成・編集・削除（品目・数量・単価・税率から自動計算）
- PDF出力（ブラウザ内で生成、サーバー送信なし）
- 全データのJSONバックアップ書き出し／読み込み（インポートは全置換）

### 含まないもの（次サイクル以降の検討事項）

- 複数端末間のデータ同期（サーバーが必要になるため、意図的にスコープ外）
- 会社ロゴ・印影画像の合成（第三者権利物の取り扱いを慎重にするため見送り）
- PDFへの日本語フォント埋め込み（下記「既知の制約」参照）
- 自動更新機能（GitHub Releases の新版を都度確認する運用を想定）
- 入力値のマイナス値バリデーション（現状は数値としてそのまま計算されます）

## 起動手順（開発）

```bash
npm install
npm run dev
```

ブラウザで表示されたURL（例: http://localhost:5173）を開いてください。

## ビルド手順

```bash
npm run build   # dist/ に静的ファイルを生成
npm run preview # ビルド結果をローカルで確認
```

`dist/` フォルダの中身をそのままZIP配布、または任意の静的ホスティングに配置すれば動作します。

## テスト・型チェック

```bash
npm run check      # 型チェック + ユニットテスト
npm run typecheck   # 型チェックのみ
npm run test        # ユニットテストのみ
```

自動テストはユニットテスト（計算ロジック・IndexedDB操作・バックアップの往復）のみを含みます。
UIの結合動作（クリック操作・PDF/バックアップのダウンロード）は本サイクルでは Playwright を使った
手動スモークテストで確認済みです（`docs/DEBUG_LOG.md` 参照）。自動E2Eスイートとしての整備は未実施です。

## データの保存場所

- ブラウザの IndexedDB（データベース名: `offline-invoice-maker`）に保存されます。
- ブラウザのプロファイルやキャッシュを削除するとデータも失われます。**定期的に「バックアップ書き出し」でJSONファイルを保存し、別の場所に保管してください。**
- 「バックアップ読み込み」は現在のデータを**すべて置き換えます**（部分マージではありません）。

## 既知の制約

- PDF出力は英語ラベルの定型レイアウトです。生成に使用している jsPDF の標準フォントは日本語グリフを
  含まないため、会社名・備考などに日本語を入力すると PDF 上で正しく表示されない可能性があります。
  日本語フォントの埋め込みには追加のフォントファイル同梱とライセンス確認が必要なため、本サイクルでは
  見送りました。次サイクルでの改善候補です。
- 数量・単価にマイナス値を入力しても弾かれません（返金行などを意図的に許容していますが、誤入力の
  ガードはありません）。
- 依存ライブラリ（jsPDF）が内部で参照する `html2canvas` / `dompurify` を含むため、ビルド後のJSバンドルが
  やや大きめです（メイン機能では未使用の依存です）。動作に支障はありませんが、次サイクルで軽量なPDF
  生成方法への置き換えを検討の余地があります。
