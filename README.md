## このリポジトリについて
AIオーケストレーターによる「市場調査→企画→実装→テスト→法務レビュー→デプロイ準備→マーケ素材作成」の日次サイクルで、小型Webツールを開発・蓄積していくリポジトリです。

各サイクルの成果物は `projects/YYYY-MM-DD-<project-slug>/` 配下に格納され、その日の活動記録は `reports/YYYY-MM-DD.md` にまとめられています。

**注意**: ドメイン取得・決済導入・独自ドメインでの一般公開・有料APIやクラウドリソースの新規契約は、いずれも人間の承認と実行が必要な領域として、このリポジトリの自動サイクルでは行っていません。各プロジェクトの `DEPLOY.md` に人間が行うべき作業をまとめています。
