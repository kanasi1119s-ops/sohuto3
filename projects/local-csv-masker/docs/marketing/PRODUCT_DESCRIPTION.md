# 商品説明文（BOOTH / Gumroad 用）
**Local CSV Masker ― CSV・テキストの個人情報を、端末の中だけでマスキング**

ZIPを展開して index.html を開くだけ。インストール不要、通信なし、オフライン対応のツールです。

■ 検出: メール / 電話（全角可）/ 郵便番号 / マイナンバー / カード番号 / IPv4 / 指定語
■ 方式: 伏字・部分マスク・仮名化　■ 列ごとの保持・マスク・削除
■ Shift_JIS CSV 対応、UTF-8(BOM付き)で保存　■ 設定JSONの入出力

【ご注意】正規表現ベースのため、検出漏れ・誤検出の可能性があります。氏名・住所の自動検出は行いません。匿名化の完全性は保証できません。出力内容は必ずご確認ください。
同梱: 本体(ZIP)、README、利用許諾契約。動作確認: Chromium系ブラウザ（他ブラウザは未検証）。
