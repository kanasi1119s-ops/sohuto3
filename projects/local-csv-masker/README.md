# Local CSV Masker

CSV・テキストに含まれる個人情報を、**ブラウザの中だけ**でマスキングするツールです（配布形態: L1 ブラウザ完結 / PWA）。
生成AIや外部委託先にデータを渡す前の下処理を想定しています。データは端末外へ送信されません（CSP `connect-src 'none'`）。

## 機能
- 検出: メール / 電話番号（国内・全角対応）/ 郵便番号 / マイナンバー（チェックデジット検証）/ クレジットカード番号（Luhn検証）/ IPv4 / ユーザー指定語
- マスク方式: 伏字 `[EMAIL]` / 部分マスク `t***@example.com` / 仮名化 `EMAIL_001`（同一値は同一名）
- 列ルール: 自動 / 保持 / 列ごとマスク / 削除（氏名・住所の列はこれで処理）
- Shift_JIS(CP932) の CSV を自動判別して読み込み、UTF-8（BOM付き選択可）で保存
- 設定のエクスポート/インポート（JSON）。前回設定はブラウザの localStorage に保存
- オフライン動作（Service Worker）。テレメトリ・解析は一切なし

## 起動
```bash
npm ci
npm run dev        # 開発サーバー
npm run build      # dist/ に静的ファイルを生成（ZIPで配布、または静的ホスティング）
npm run preview    # ビルド結果を http://localhost:4173 で確認
```

## テスト
```bash
npm run check      # lint + 型チェック + ユニットテスト
npx playwright install chromium   # 初回のみ（既にChromiumがある場合は CHROMIUM_PATH=/path/to/chrome）
npm run test:e2e   # E2E（ビルドして preview サーバーを自動起動）
```

## データの保存場所
- 入力データは保存しません（メモリ上のみ）。
- 設定のみ localStorage（キー: `csv-masker-profile`）。設定JSONのエクスポートでバックアップできます。

## 制限事項
- 氏名・住所の自動検出は行いません（列ルールを使用）。正規表現ベースのため、見逃し・過検出があり得ます。**完全な匿名化を保証しません**。出力は必ず目視確認してください。
- 10〜11桁の数字が 0 始まりだと電話番号と誤検出することがあります。
- 見出し名が重複する列は同じ列ルールを共有します。
- 上限ファイルサイズ 50MB。
- Service Worker はキャッシュ優先です。更新後に古い画面が出る場合は再読み込みしてください。
