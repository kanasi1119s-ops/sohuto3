# 設計

## 要件(MVP)
- 複数ファイルの追加(ドロップ/選択)、行ごとに 取引年月日・取引先・取引金額・書類種別 を編集
- ファイル名から日付/金額/取引先を推測(下書き。金額は ¥・円・3桁カンマの目印がある場合のみ)
- 命名: `YYYYMMDD_取引先_金額円[_種別].ext`。同名は `_2`, `_3` で一意化(大文字小文字無視)
- 出力: ZIP(STORE、UTF-8ファイル名)+ 索引台帳CSV(BOM付きUTF-8、日付昇順)
- 取引先辞書(別名→正規名)。NFKC・小文字・空白除去で照合。CSV入出力
- オフライン動作(Service Worker)、外部通信ゼロ

## 含まない(MVP外)
OCRによる自動読取、フォルダへの直接リネーム(File System Access API)、タイムスタンプ付与、帳簿(仕訳)連携、自動更新

## 命名の仕様
| 項目 | 規則 |
|---|---|
| 日付 | 西暦/和暦(令和・平成・昭和、R/H/S、元年)を `YYYYMMDD` に正規化。実在しない日付は不可 |
| 取引先 | 禁止文字 `\ / : * ? " < > |` と制御文字を除去、`_` は `＿` に置換、前後の空白/ドットを除去、最大60文字 |
| 金額 | 0以上の整数(円)。全角・¥・円・カンマ可。最大13桁 |
| 種別 | 任意。最大20文字 |
日付・金額は切り詰めない(検索要件の項目を保持するため)。

## 構成
- `src/core/*` 純粋関数(date, amount, name, rows, guess, dict, csv, zip, crc32)— ユニットテスト対象
- `src/main.ts` DOM。入力欄は再生成せず `refresh()` で結果セルだけ更新(IME保護)
- `public/sw.js` 同一オリジンGETのみキャッシュ(network-first)

## セキュリティ設計
- CSP: `default-src 'self'; connect-src 'self'; object-src 'none'` 等
- DOMは `textContent` のみ使用(innerHTML不使用)
- CSV: 先頭が `= + - @ タブ CR` のセルに `'` を付与(数式インジェクション対策)
- 辞書は `__proto__` を拒否、辞書CSVは5MBまで
- ZIPは合計約3.75GiB/65535件まで(超過時はエラー表示)
