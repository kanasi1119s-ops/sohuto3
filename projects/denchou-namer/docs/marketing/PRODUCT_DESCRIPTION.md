# 商品説明文(BOOTH/Gumroad用・コピペ可)
**【買い切り・オフライン】電帳ネーマー — 請求書・領収書のファイル名を「日付_取引先_金額」に一括変換**

受け取ったPDFや画像に、取引年月日・取引先・金額を入れた名前を付けて、索引台帳CSVと一緒にZIPで保存するツールです。ブラウザで動き、ファイルは端末の外に送信されません。

■ 主な機能
- 複数ファイルを一括処理 / ファイル名からの下書き推測
- 和暦・全角・¥/円/カンマ表記に対応
- 同名ファイルの自動連番、禁止文字の自動除去
- 索引台帳CSV(UTF-8 BOM付き)をZIPに同梱
- 取引先の表記ゆれ辞書(CSVで保存・読込)

■ 動作環境: 最新のChrome / Edge / Firefox / Safari(ブラウザ)。同梱ZIPを展開してローカルHTTPサーバー等で開くか、静的ホスティングに置いて使用します(詳細は同梱README)。
■ ご注意: 電子帳簿保存法の要件充足を保証するものではありません。OCR・タイムスタンプ付与・フォルダ直接リネームは非対応です。
