# 公開手順書（人間向け）

このツールはビルド不要の静的サイト（HTML/CSS/JSのみ）です。以下は本番公開時に**人間が実行する**手順です。Claudeはドメイン取得・本番反映・課金導入は行いません。

## ビルド確認結果（DevOpsフェーズで実施済み）
- `node --check script.js` → 構文エラーなし
- HTML構文チェック → エラーなし
- 静的ファイル配信確認（`python3 -m http.server`）→ 200 OK
- Chromium headlessでの表示・操作確認 → QA.md参照

## 公開先の選択肢（例）
1. **GitHub Pages**（無料・最も手軽）
   - リポジトリの Settings → Pages で `projects/2026-09-27-kaigi-cost-meter` を公開ディレクトリに設定
   - もしくは `gh-pages` ブランチに当該ディレクトリの内容をコピーして公開
2. **Vercel / Netlify**（無料枠あり、独自ドメイン接続も容易）
   - リポジトリを連携し、Root Directoryを `projects/2026-09-27-kaigi-cost-meter` に指定してデプロイ

## 公開前に人間が行うべきこと
- [ ] 独自ドメインを使う場合はドメイン取得・DNS設定
- [ ] プライバシーポリシーページの最終確認（LEGAL.md参照）
- [ ] 実機（Safari/Firefox/モバイル）での表示・操作確認
- [ ] OGP画像・favicon等の追加（今回のMVPには含まれていない）
- [ ] 独自ドメイン公開後、SNS告知文（SNS.md）を投稿

## 課金機能について
本サイクルでは決済導入・有償プラン実装は行っていません。有償化を検討する場合は、Stripe等の決済サービスの本番接続を含め、人間の承認を得た上で別サイクルで実装してください。
