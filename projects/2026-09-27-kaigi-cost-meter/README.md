# 会議コストメーター (Kaigi Cost Meter)

参加人数と概算給与から「今この会議にいくらかかっているか」をリアルタイムに可視化する、会議室のモニターに映すための無料Webツールです。

企画の背景・スコアリングは [CONCEPT.md](./CONCEPT.md) を参照してください。

## 特徴
- サーバー不要・アカウント不要の静的サイト（HTML/CSS/JavaScriptのみ）
- 入力データはブラウザの `localStorage` にのみ保存され、外部送信は一切なし
- 会議室のモニターに映すための「大画面表示モード」を搭載
- 会議終了後のサマリーをテキストとしてコピー可能

## 起動方法（ローカル確認）
ビルド不要の静的ファイルです。ブラウザで `index.html` を直接開くか、簡易サーバーで確認できます。

```bash
cd projects/2026-09-27-kaigi-cost-meter
python3 -m http.server 8787
# ブラウザで http://localhost:8787 を開く
```

## 使い方
1. 参加人数と参加者の平均年収帯を選択
2. 「会議を開始する」をクリックすると経過時間とコストがリアルタイムに表示される
3. 必要に応じて「大画面表示」でフルスクリーン化し、会議室のモニターに投影
4. 「会議を終了する」でサマリーを表示し、「結果をコピー」でテキストとして共有可能

## 既知の制約（MVP時点）
- 時給換算は「年収 ÷ 1700時間」という簡易的な概算であり、実際の人件費（社会保険料・福利厚生費等を含む会社負担コスト）とは異なります。画面上にもその旨を明記しています。
- ユーザーアカウント・会議履歴の保存機能はありません（意図的にスコープ外）。
- 決済・課金機能は未実装です（Legal/DevOpsの都合上、本サイクルでは実装しません）。
