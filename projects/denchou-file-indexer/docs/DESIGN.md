# denchou-file-indexer 設計（企画段階・未実装）

- 1行コンセプト: 受け取った請求書・領収書ファイルに「日付_取引先_金額」の命名を付け、日付/金額/取引先で検索できる台帳を端末内だけで作る。
- ターゲット: 電子取引データの保存義務がある個人事業主・小規模事業者。
- 配布形態: **L1**（静的SPA/PWA、IndexedDB）。理由: サーバー不要、データが端末外に出ない、買い切り/無料配布が容易。
- 収益化仮説: 買い切り（署名付きライセンスキー、オフライン検証）。※仮説であり収益は保証されない。
- スコア: 需要4 / 難易度4 / 法的リスク4 / 差別化3 / 運用コスト5 = **20/25**

## MVPスコープ
含む: レコード登録（取引日・金額・取引先・備考・ファイル名・SHA-256）、命名候補生成、日付範囲/金額範囲/取引先の検索、JSON/CSVエクスポート・インポート、オフライン動作。
含まない: ファイル本体の保管、OCR、クラウド同期、自動更新。

## 注意（Legal）
「電子帳簿保存法に完全対応」等の断定表現は使わない。要件充足の最終確認は税理士/国税庁資料で人間が行う。
