# 公開手順書（人間が実行してください）

このドキュメントは、コネクロス (ConneCross) を実際に公開する際の手順をまとめたものです。**ビルド・公開作業そのものはこのサイクルでは実行していません。** 以下はすべて人間（プロジェクトオーナー）が判断・実行する前提の手順です。

## 0. 前提

- ローカルでの起動確認方法は `README.md` を参照してください。
- 公開前に、最低でも人間同士で1〜2回テストプレイし、実際の「面白さ」を確認することを強く推奨します（AIシミュレーションだけでは判定できない要素です）。

## 1. ビルド

```bash
npm ci
npm run build
```

`dist/` ディレクトリに静的サイトが生成されます。`vite.config.ts` で `base: './'` を指定しているため、どのパス配下にデプロイしても相対パスで動作します。

## 2. GitHub Pages で公開する場合

1. リポジトリの Settings → Pages で、公開ブランチ・ディレクトリを設定する（例: `gh-pages` ブランチ、または GitHub Actions からのデプロイ）。
2. `.github/workflows/ci.yml` はビルドとテストのみを行うワークフローです。Pages への自動デプロイを行いたい場合は、`actions/deploy-pages` 等を使った追加のワークフローを人間の判断で追加してください（本サイクルでは自動デプロイ設定は行っていません）。
3. 公開後、モバイル・PC双方のブラウザで実際に対局が最初から最後まで遊べることを確認してください。

## 3. itch.io で公開する場合

1. `npm run build` で生成された `dist/` フォルダの中身一式をzip圧縮する。
2. itch.io のプロジェクト作成画面で「HTML」タイプを選択し、zipファイルをアップロードする。
3. 「このファイルをブラウザで再生する（This file will be played in the browser）」にチェックを入れる。
4. 価格設定（無料 / 投げ銭 / 有料）は `docs/sales-copy.md` の価格案を参考に人間が決定してください。
5. ストアページの説明文には `docs/sales-copy.md` の文言をそのまま利用できます。

## 4. Print & Play 版を配布する場合

- `docs/print-and-play.md` に物理版で遊ぶための盤面テンプレート・カード内訳を記載しています。
- 印刷用PDFが必要な場合は、`docs/print-and-play.md` をブラウザで開き「印刷→PDFとして保存」するか、Pandoc等のツールで変換してください。

## 5. 公開前チェックリスト（人間向け）

- [ ] 人間同士で実際に1〜2回プレイし、面白さ・ルールの分かりやすさを確認した
- [ ] ゲームタイトル「コネクロス／ConneCross」の商標調査を行った（`docs/legal-review.md` #2）
- [ ] 公開先（GitHub Pages / itch.io / その他）を決定した
- [ ] 価格・販売形態を決定した（無料の場合はこのチェックリストの以降の項目は不要）
- [ ] 有料販売する場合、特定商取引法に基づく表記を用意した（`docs/legal-review.md` #7）
- [ ] 個人情報を扱う機能（アカウント等）を追加する場合、プライバシーポリシーを用意した
- [ ] SNS告知文・ストア文言を最終確認した（`docs/sales-copy.md`）

## 6. 費用が発生する作業について

ドメイン購入、有料API契約、クラウドリソースの新規契約、決済機能の本番接続など、費用が発生する作業は本サイクルでは一切行っていません。これらは人間が必要性を判断のうえ実施してください。
