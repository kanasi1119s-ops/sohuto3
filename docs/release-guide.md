# 公開手順書（人間向け）

このドキュメントは、開発したゲームを実際に公開・販売する際に**人間が行うべき作業**をまとめたものです。AI（Claude）はこれらの作業を自動実行しません。

## 1. GitHub Pagesで公開する場合

1. GitHubでこのリポジトリの **Settings → Pages** を開き、「Build and deployment」の **Source** を「**GitHub Actions**」に設定する。
2. **Settings → Secrets and variables → Actions → Variables** タブで、新しいリポジトリ変数を追加する:
   - 変数名: `ENABLE_PAGES_DEPLOY`
   - 値: `true`
3. `main` ブランチに何かをpushするか、GitHubの **Actions** タブから `Build and Deploy Pages` ワークフローを手動実行（workflow_dispatch）する。
4. Actionsの実行結果で `build` ジョブが成功し、`deploy` ジョブも実行されたことを確認する。
5. 公開後のURL `https://<ユーザー名>.github.io/<リポジトリ名>/` にアクセスし、実際に最後までプレイできることを確認する。
6. **公開を止めたい場合**: リポジトリ変数 `ENABLE_PAGES_DEPLOY` を削除し、Settings → Pages で公開を解除する。

> 補足: `ENABLE_PAGES_DEPLOY` が設定されていない、または `true` 以外の場合、`deploy` ジョブは自動的にスキップされます（失敗にはなりません）。`build` ジョブ（テスト・ビルド）は常に実行され、pushのたびに壊れていないかを確認できます。

## 2. itch.io で公開する場合

1. `./scripts/build-itch-zip.sh` を実行し、`dist/nine-territory-itch.zip` を生成する。
2. itch.io で新しいプロジェクトを作成し、種別を「HTML」にする。
3. 生成したzipをアップロードし、「**This file will be played in the browser**」にチェックを入れる。
4. 埋め込みビューポートのサイズ（横幅・縦幅）を、スマホ〜デスクトップの両方で確認しながら調整する。
5. 価格設定（無料 / 投げ銭 / 有料）・公開範囲（Draft / Public）を決定し、公開する。

## 3. Print & Play（印刷して遊ぶ版）を用意する場合

現状、盤面は5×5マス・タイルは1〜9の数字のみといたってシンプルな構成のため、専用PDFがなくても以下で代用可能です。

1. 方眼紙やホワイトボードに5×5のマス目を描く。
2. 青・赤それぞれの色の紙またはカードに1〜9の数字を1枚ずつ書き、計18枚を用意する。
3. `docs/rules.md` を印刷して配布する。

専用のレイアウト済みPDF（カード・盤面デザイン込み）を用意したい場合は、次サイクル以降にDevOpsフェーズで作成を検討してください。

## 4. 法務・表記に関する確認事項（公開前に必ず人間が確認）

- ゲームタイトル「ナインテリトリー」について、既存の商標・商品名と紛らわしくないか、正式な商標調査を行ってください（本サイクルでは簡易的な確認のみ）。
- 有料販売を行う場合、特定商取引法に基づく表記が必要になる場合があります。事業者情報の記入は人間が行ってください。
- ユーザー登録・ランキング機能等で個人情報を扱う場合は、プライバシーポリシーを別途用意し、公開前に必ず確認してください（本MVPではそのような機能はありません）。

## 5. 決済・課金について

本MVPには課金・決済機能は一切含まれていません。投げ銭やダウンロード販売を行う場合は、対象プラットフォーム（itch.io, BOOTHなど）の決済機能を人間が設定してください。AIが決済・課金の本番接続を行うことはありません。
