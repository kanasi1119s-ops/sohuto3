# 法務レビュー（Phase 6）

## チェックリスト

- [x] **第三者コンテンツの権利処理**: 本アプリは画像・フォント・アイコン等の第三者コンテンツを一切
      使用していない（UIはCSSのみで構成、外部フォント・画像なし）。ロゴ・印影画像の合成機能はスコープ外
      とした（README「含まないもの」参照）。
- [x] **スクレイピング**: 該当なし（本アプリは外部サイトへのアクセスを一切行わない）。
- [x] **個人情報の取り扱い**: 顧客の氏名・住所・メールアドレスを扱うが、**すべて利用者の端末内
      （IndexedDB）にのみ保存され、外部送信は一切行わない**設計。プライバシー方針案は下記参照。
      ★正式なプライバシーポリシーの整備・公開判断は人間が行うこと。
- [x] **特定商取引法**: 本ソフトウェアを有償配布する場合、特定商取引法に基づく表記
      （事業者名・所在地・連絡先・返金条件等）が販売ページに必要になる。
      ★事業者情報の記入・掲載は人間が行うこと（本サイクルでは記入しない）。
- [x] **利用許諾契約（EULA）・免責事項**: `LICENSE` に雛形を用意（非独占的ライセンス、再配布禁止、
      現状有姿での提供・免責）。★事業者名・準拠法・返金ポリシーの確定は人間が行うこと。
- [x] **OSSライセンスとの整合性**: `docs/THIRD_PARTY_LICENSES.md` の内容と、配布物へのライセンス
      同梱方法（README からのリンク＋ファイル同梱）が整合していることを確認済み。
- [x] **誇大表現のセルフチェック**: マーケティング文言（`docs/marketing/`）に「必ず」「絶対に」といった
      断定的な効果保証・収益保証の表現がないことを確認済み。

## プライバシー方針（案・要人間確認）

> 本ソフトウェアは、入力されたすべてのデータ（顧客情報・見積書・請求書データ）を利用者の端末内
> （ブラウザのIndexedDB）にのみ保存します。開発者を含む第三者のサーバーにデータが送信されることは
> ありません。バックアップファイルのエクスポート・インポートは利用者自身の操作によってのみ行われます。

★このドラフトを実際にLP等に掲載する前に、人間による最終確認を推奨する。

## 残課題（人間の確認が必要な項目）

- プライバシーポリシー本文の最終確認・公開判断
- 特定商取引法に基づく表記への事業者情報の記入
- LICENSE雛形への事業者名・準拠法・返金ポリシーの記入
