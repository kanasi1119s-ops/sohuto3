# 法務レビュー チェックリスト

対象: カラーフィールド (Color Field) v0.1 MVP
実施者: Legal-Reviewerフェーズ（Claude）／最終判断は人間が行うこと

- [x] **既存作品との類似**: ルール（隣接拡張＋最大連結成分での勝敗判定＋
      限定回数のジャンプ配置）は本プロジェクトで独自に設計したものであり、
      特定の市販タイトルの名称・テーマ・ルール文言・カードテキスト・
      盤面デザインを模倣していない。抽象戦略ゲームというジャンルの
      一般的な要素（グリッド配置、陣地拡張、連結判定）は多くの作品に
      共通する汎用的な仕組みであり、特定作品の「クローン」には当たらないと判断。
- [ ] **商標**: 「カラーフィールド / Color Field」という名称について、
      既存の商品名・ゲーム名との衝突有無は未調査（簡易Web検索での
      重大な衝突は確認していないが、正式な商標調査・出願判断は
      人間が行うこと。★要対応）。
- [x] **素材の権利**: 画像・イラスト・効果音・フォントは一切使用せず、
      OS標準システムフォントと絵文字のみを利用。`CREDITS.md` に記録済み。
      商用利用不可の素材は使用していない。
- [x] **実在の人物・団体・キャラクター**: 一切使用していない（架空の
      色名「アンバー」「アジュール」のみ）。
- [x] **賭博・景品**: 現金・換金可能な価値を賭ける仕組みは実装していない。
      有料ランダム要素（ガチャ等）も実装していない。将来的にガチャ的な
      要素を検討する場合は景品表示法・資金決済法の確認が必要（★現時点では該当なし）。
- [x] **個人情報**: ユーザー登録・ランキング等の機能は実装しておらず、
      個人情報を一切取得しない（完全ローカル動作、通信なし）。
- [ ] **特定商取引法表記**: 現時点では無償・非公開のMVPであり該当しないが、
      将来有料販売する場合は特定商取引法に基づく表記（事業者情報等）が
      必要になる。実際の事業者情報の記入は人間が行うこと（★要対応、公開判断時）。
- [x] **対象年齢・表現**: 暴力・グロテスク・差別的表現は一切含まれない
      抽象的な色・図形のみのデザイン。対象年齢8歳以上として問題なし。
- [x] **誇大表現**: ストア文言・SNS告知文（`docs/sales/`）に「必ずハマる」
      「No.1」等の根拠のない断定表現がないことをSales-Writerフェーズで
      Self-check済み。

## 総合判定
上記のうち★2件（商標の正式調査、特定商取引法表記の事業者情報記入）を
除き、確認済み。この2件は公開判断時に人間が対応すること。それ以外に
本MVPを社内的に開発・テストプレイする上での法務上のブロッカーはない。
