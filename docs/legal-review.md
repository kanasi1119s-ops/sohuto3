# 法務レビュー（LinkForge）

実施日: 2026-09-27　レビュー対象: LinkForge（リンクフォージ）MVP一式

## チェックリスト

- [x] **既存作品との類似**: 「盤面に石を置いて5連結を作る」という勝利条件自体はGomoku/五目並べ系に共通する一般的なメカニクスであり、特定の権利者が独占できるものではないと判断。一方、タイトル名・盤面サイズ(7×7)・パイルール（開幕スワップ）・フォージ（限定回数の相手石除去＋猶予期間付き）という組み合わせは独自設計であり、市販の特定タイトルの名称・見た目・詳細ルールをそのまま模倣した「クローン」には該当しないことを確認した。
- [x] **商標**: 「LinkForge」というタイトル（仮称）が国内外の既存の商品名・ゲームタイトルと紛らわしいかどうかは、本セッションでは簡易確認にとどまる。**正式な商標調査・出願要否の判断は人間が行うこと**（★人間確認事項）。
- [x] **素材の権利**: 本MVPは画像・イラスト・効果音・独自フォントを一切使用せず、CSSによる図形描画（円・グリッド）とシステムフォントのみで構成した。使用した外部ライブラリはReact/Viteのみで、いずれもOSSライセンス（MIT等）に基づく開発用ツールであり、成果物への著作権表示義務はない。`CREDITS.md` に記録済み。
- [x] **実在の人物・団体・キャラクター**: 使用していない（該当なし）。
- [x] **賭博・景品**: 現金・換金可能な価値を賭ける仕組みは実装していない。ランダム型有料アイテム（ガチャ等）も実装していない。将来、有料のランダム要素を検討する場合は景品表示法・資金決済法の確認が別途必要になることを明記する（★人間確認事項、現時点では計画なし）。
- [x] **個人情報**: ユーザー登録・ログイン・ランキング機能は一切実装しておらず、個人情報の取得は発生しない。
- [ ] **特定商取引法に基づく表記**: 本MVPは無料・アカウント登録なしのブラウザゲームであり、現時点で有料販売は行っていないため未対応。**将来、有料版・投げ銭等の金銭のやり取りを伴う形で公開する場合は、特定商取引法に基づく表記（事業者情報等）の追加が必要**（★人間確認事項）。
- [x] **対象年齢・表現**: 暴力的表現、差別的表現、性的表現は一切含まれない。抽象的な石・盤面のみで構成されており、全年齢向けとして問題ない。
- [x] **誇大表現**: `docs/sales-copy.md` のストア文言・SNS告知文について、「必ず」「No.1」等の根拠のない断定表現を使用していないことをSales-Writerフェーズで自己チェック済み。

## 総合判定

**「要対応」の残課題は2件、いずれも公開・収益化段階で人間が対応すべき事項であり、現時点のMVP（無料・非公開の開発用ビルド）としては法務上のブロッカーはない。**

### ★人間の確認・対応が必要な項目
1. 「LinkForge」というタイトル名の商標調査・出願要否の判断
2. 将来的に有料販売・投げ銭等を行う場合の特定商取引法に基づく表記の準備、および有料ランダム要素を検討する場合の景品表示法・資金決済法の確認
