# 法務レビュー（Legal-Reviewer フェーズ）

対象: ナインテリトリー MVP

- [x] **既存作品との類似**: ゲーム名・テーマ・ルールの組み合わせを確認。「数字タイルを置いて隣接する弱い数字を奪う」というメカニクス自体は抽象戦略ゲームのジャンルとして一般的な要素の組み合わせだが、特定の市販タイトル（名称・カードテキスト・盤面デザインを含む）をそのまま模倣したものではない。既存の有名ボードゲームのクローンには該当しないと判断。
- [ ] **商標**: 「ナインテリトリー」というタイトルについて、既存の商品名・ゲーム名との衝突がないか、正式な商標データベースでの調査は行っていない。**これは人間が公開前に行うべき最終確認事項です**（`docs/release-guide.md` に記載）。
- [x] **素材の権利**: 画像・イラスト・効果音・アイコンは一切使用していない（CSSによる図形描画とOS標準フォントのみ）。`CREDITS.md` に記録済み。
- [x] **実在の人物・団体・キャラクター**: 使用していない。
- [x] **賭博・景品**: 現金・換金可能な価値を賭ける仕組みは一切ない。ランダム要素そのものがゲーム内に存在しない（完全情報ゲームのため）。将来的に有料ランダム要素（ガチャ等）を検討する場合は、景品表示法・資金決済法の確認が必要になることを日次レポートに明記する。
- [x] **個人情報**: ユーザー登録・ランキング等の機能は実装していない。個人情報を取得する仕組みは存在しない。
- [x] **特定商取引法**: 現時点で有料販売機能は実装していないため該当しないが、将来的に有料販売を行う場合は特定商取引法に基づく表記が必要になることを日次レポートおよび `docs/release-guide.md` に明記済み。
- [x] **対象年齢・表現**: 暴力的表現・差別的表現は一切含まれていない（抽象的な数字と色のみ）。対象年齢8歳以上として問題ないと判断。
- [x] **誇大表現**: ストア文言・SNS告知文（`docs/marketing.md`）に「必ず」「No.1」等の根拠のない断定表現がないことをSelf-checkし、該当なしを確認。
- [x] **公開前提の確認**: リポジトリ内にシークレット・APIキー・個人情報・未ライセンス素材は含まれていない（依存パッケージ・外部素材ともに0件のため、GitHub Pagesで公開しても問題ない構成）。

## 総合判定

**「要対応」項目は商標の正式調査のみ**であり、それ以外の法務チェックはすべて確認済み。商標調査が完了するまでは、ゲームタイトルを変更する可能性がある前提で運用することを推奨する。
