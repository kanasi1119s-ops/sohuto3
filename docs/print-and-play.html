ラインクラフト（Line Craft） — Print & Play キット

このページを印刷し、タイルを1枚ずつ切り分け、盤面を厚紙などに貼って物理版としてお楽しみください。プレイヤー用マーカー（碁石・色付きシール等）を各色1セット別途ご用意ください。

タイル一覧（16枚：1・2・3・4を各4枚、切り取ってお使いください）

盤面（4x4マス、コピーまたは厚紙に拡大転写してお使いください）

ルール要約

ラインクラフト（Line Craft） ルール要約 ■ コンセプト 場に並ぶ3枚のタイルから1枚を選び、盤上4x4マスの好きな場所に置く。 縦・横・斜め、合計10本のラインで相手より合計値が大きいラインを多く作った方が勝ち。 ■ 準備 16枚のタイルをよく混ぜ、山札にする。上から3枚を表にしてマーケットとして並べる。 ■ 手番（P1, P2, P2, P1 の4手を1ブロックとして繰り返す） 1. マーケットから1枚選んで手に取る 2. 盤面の空いているマスに置く（自分の色として記録） 3. 山札の一番上をマーケットに補充する（山札切れなら補充なし） ■ 終了・得点 16マスが埋まったら終了（必ず16手＝各8手で終わる）。 各ライン（4マス）で自分の置いた数字の合計が相手より大きければ1点、同点ならそのラインは無得点。 ライン得点が多い方が勝ち。同点なら盤面全体の合計値で判定、それも同じなら引き分け。 詳しいルール・プレイ例は docs/rules.md を参照してください。 デジタル版はブラウザで `npm run dev` の後 http://localhost:5173 でも遊べます。
