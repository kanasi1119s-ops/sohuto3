# Legal レビュー チェックリスト (Phase 6)

- [x] **第三者コンテンツの権利処理**: 画像・フォント・アイコン・文章素材は一切使用していない（純粋なCSS/DOM UI）。ロゴ・アイコン素材が必要な場合は次サイクルでオリジナル作成またはライセンス確認済み素材のみを使用する。
- [x] **スクレイピング**: 本アプリは外部サイトへのアクセスを一切行わない（`connect-src 'none'`）。該当なし。
- [x] **個人情報の扱い**: アプリ自体は利用者が自発的に入力する認証情報（ユーザー名・パスワード等）のみを扱い、開発者側のサーバーには一切送信されない。プライバシー方針案は [PRIVACY_POLICY_DRAFT.md](PRIVACY_POLICY_DRAFT.md) を参照（★最終確認は人間が行うこと）。
- [ ] ★**特定商取引法に基づく表記**: 将来、本ソフトウェアを有償販売する場合は特定商取引法に基づく表記（事業者名・所在地・連絡先・返品条件等）が必要になる。実際の事業者情報の記入は人間が行うこと。雛形は [TOKUSHOHO_TEMPLATE.md](TOKUSHOHO_TEMPLATE.md) に用意した。
- [x] **EULA・免責事項**: 案を [EULA_DRAFT.md](EULA_DRAFT.md) / [DISCLAIMER.md](DISCLAIMER.md) に用意。★最終確認・法的な妥当性の確認は人間（可能であれば専門家）が行うこと。
- [x] **OSSライセンスとの整合性**: Securityフェーズで確認済み（コピーレフト依存なし、ランタイム依存0件）。配布物への著作権表示は不要（サードパーティコードを含まないため）。開発ツールチェーンのライセンス一覧は [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md) に同梱。
- [x] **誇大表現・効果保証の禁止**: `docs/marketing/` のLP・SNS文言をセルフチェック。「絶対に安全」「100%破られない」等の断定的なセキュリティ保証表現は使用していない（Sales-Writerフェーズのセルフチェック参照）。

## 総合判定

★人間確認が必要な項目: 特定商取引法の実際の事業者情報記入、EULA/プライバシーポリシーの最終法的確認、（将来）第三者セキュリティ監査の実施判断。それ以外は本サイクルで確認・文書化済み。
