# 特定商取引法に基づく表記（雛形・要人間記入）

有償販売を行う場合に必要です。★すべての項目を人間が実際の情報で記入してください。AIはこの雛形にダミーの事業者情報を記入していません。

| 項目 | 内容 |
|---|---|
| 販売事業者 | ★記入 |
| 運営統括責任者 | ★記入 |
| 所在地 | ★記入（請求があれば遅滞なく開示する場合は「請求により開示」も可、法令要件を確認） |
| 電話番号 | ★記入 |
| メールアドレス | ★記入 |
| 販売価格 | ★記入 |
| 販売価格以外の必要料金 | 該当なし（買い切りDL販売の場合） |
| 支払方法 | ★記入（例: Stripe / BOOTH / Gumroad 経由） |
| 支払時期 | ★記入 |
| 引き渡し時期 | 決済確認後、即時ダウンロード可能 |
| 返品・キャンセル | ★記入（デジタルコンテンツの性質上、原則返金不可とする場合はその旨明記） |
| 動作環境 | モダンブラウザ（Chrome/Edge/Firefox/Safari 最新版）。ネットワーク接続不要。 |
