- 採用した案: LinkForge。理由: itch.io上の2人用アブストラクトゲームには「日本語UI＋AI内蔵」という機能ギャップが見られ、BoardGameGeekでも短時間・少人数のコネクション/エリアコントロール系が引き続き注目されているため（詳細・出典URLは [docs/pdm-research.md](pdm-research.md) 参照）

## ゲームデザイン

- コアループ: 空いているマスに自分の石を置くか、限られた回数だけ相手の石を奪って置き直す「フォージ」を使い、先に自分の石を5つ連結させる
- ルールブック: [docs/rules.md](rules.md)
- バランス設計の仮説: パイルール（開幕スワップ）による先手有利の緩和、フォージの「3連結未満かつ置かれてから2ターン以上経過」という二重の制限による支配戦略の抑制（詳細はルールブック参照）

## デバッグ・テストプレイ結果（3ラウンド）

| ラウンド | 発見した問題数 | 主な修正内容 | 残課題 |
|---|---|---|---|
| 1 | 2（うち1件は致命的） | フォージに「置かれてから2ターン以上経過」という猶予期間を追加し、開いた三への対抗ブロックを即座に取り消される必勝バグを修正。AIに1手先読みの自殺手・オープンフォー回避とタイブレーク乱数を追加 | - |
| 2 | 1（軽微） | MAX_TURNS定数の計算ミス（開幕スワップ分の計上漏れ、55→56に修正） | - |
| 3 | 0（回帰なし） | - | greedy AIは1手先読みのみのため、理論上さらに深い詰み筋を見逃す可能性は残る |

- シミュレーション結果（ラウンド3・最終）: greedy vs greedy（パイルール有り）1000戦で先手51.8%/後手48.2%、パイルール無し比較対照では先手56.3%/後手43.7%（パイルールが先手有利を約4.5pt緩和）。random vs random 2000戦で先手47.6%/後手52.3%、最長手数56手（理論上限と完全一致、超過0件）。詳細は [docs/debug-log.md](debug-log.md) 参照
