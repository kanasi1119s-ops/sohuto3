## 市場・トレンド調査結果サマリ
- 採用理由: 短時間・2人用・運要素なしの頭脳戦は根強い需要があり（BoardGameGeek・itch.ioの動向）、5×5盤・タイル18枚という最小構成のため1サイクルで最後まで遊べるMVPを実装できると判断した。詳細と出典URLは `docs/market-research.md` を参照。
- 却下した案: カード運＋セット収集型ゲーム（運要素なしという差別化軸が薄れるため見送り）、多人数(3〜4人)向け陣取りゲーム（1サイクルでの完成度確保が難しいため見送り）。

## ゲームデザイン
- コアループ: 「手札から数字タイルを1枚選び、盤の空マスに置く→隣接する弱い数字の相手タイルを奪う」を両者9回ずつ、合計18手繰り返し、最後にマスを多く支配した方が勝ち。
- 日本語の説明書: [docs/rules.md](../docs/rules.md)
- バランス設計の仮説: 先手が初手を自由に置ける有利さを打ち消すため、Aの1手目直後に限りBが「スワップ」（Aの初手を奪う）を選べるパイルールを採用。高い数字の温存と解放による逆転要素、運要素ゼロによる読み合い重視の設計とした（詳細は `docs/rules.md` 9章）。

- シミュレーション結果:
  - greedy vs greedy: 5,000試行 / 先手勝率 66.4% / 後手勝率16.7% / 引分16.9% / 平均ターン数18.00
  - random vs random: 5,000試行 / 先手勝率 36.7% / 後手勝率58.5% / 引分4.8% / 平均ターン数18.00
  - **偏りの有無**: あり。ただしgreedy同士とrandom同士で有利な席が逆転しており（AI強さが混在する対戦ではAI強さの差がほぼ勝敗を決める）、これは「先手/後手という座席そのものの構造的有利さ」よりも「単純なgreedy AIの評価関数が特定の手筋に偏っていること」に起因する可能性が高いと分析している。パイルール（スワップ）による是正効果は、機械的シミュレーションだけでは十分検証できておらず、**人間同士のテストプレイでの検証を強く推奨**する（詳細: `docs/debug-log.md`）。
- 重大バグ（クラッシュ・進行不能・勝敗誤判定・終わらないゲーム）: **0件**
