# SNS告知文 草稿（2〜3パターン）

## パターン1（機能訴求）
パスワード管理、まだ月額課金してますか？
Kinko Vault はブラウザだけで動く完全ローカル完結型のパスワード保管庫。ネット接続ゼロ、データはあなたの端末の中だけ。買い切りで使えます。
#買い切りソフト #オフラインツール #個人開発

## パターン2（課題提起型）
「クラウドに預けたくないけど、パスワード管理はしたい」
そんな方のために作りました。Kinko Vault は通信を一切行わないブラウザ完結型のパスワード保管庫です。オフラインでも全機能が動きます。
#プライバシー #ローカルファースト

## パターン3（開発者向けトーン）
AES-256-GCM + PBKDF2(300,000回)でローカル暗号化する、サーバーレスのパスワード保管庫を作りました。ソースはシンプルなTS+Web Crypto APIのみ、ランタイム依存ゼロです。
#WebCryptoAPI #TypeScript #ローカルファースト
