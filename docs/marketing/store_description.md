# 商品説明文案（BOOTH / Gumroad 等）

## 商品名
Kinko Vault - ローカル完結型 暗号化パスワード保管庫

## 短い説明（1行）
サブスクなし、クラウド預けなし。ブラウザだけで完結する買い切り型パスワードマネージャー。

## 商品説明

Kinko Vault は、あなたのパスワードや秘密のメモを **あなたの端末内だけ** に暗号化して保存する、ブラウザ完結型のツールです。

**こんな方におすすめ**
- パスワード管理サービスの月額課金に疲れた方
- 機密情報をクラウドサービスに預けたくない方
- オフライン環境でも使えるツールを探している方

**特長**
- AES-256-GCM暗号化 + マスターパスワードによる保護
- インターネット接続一切不要（オフラインで全機能が動作）
- 自動パスワード生成機能つき
- バックアップ用のエクスポート/インポート機能

**ご注意**
- 本ソフトウェアはMVP段階であり、第三者セキュリティ監査は未実施です。
- マスターパスワードを紛失するとデータは復元できません。エクスポート機能で定期的にバックアップを取ってください。
- 動作環境: Chrome / Edge / Firefox / Safari の最新版（インストール不要）。

**ダウンロード後**
ZIPファイルを解凍し、`index.html` をブラウザで開くだけでご利用いただけます。
