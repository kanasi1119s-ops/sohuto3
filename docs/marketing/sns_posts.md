# SNS告知文（草稿）

## パターン1（機能訴求）

見積書・請求書を作るだけなのに、なぜかクラウドに情報を預けないといけないのが気になっていたので、
「ブラウザだけで完結・データは端末内だけ」のツールを作りました。オフラインでも使えます。
#個人事業主 #フリーランス #請求書

## パターン2（課題提起）

「取引先の情報、外部サーバーに置きたくないな」と思ったことがある方へ。
見積書・請求書作成が端末内だけで完結するツールを作りました。買い切りで、月額課金はありません。

## パターン3（軽め）

見積書アプリ作った。データは全部自分のブラウザの中。ネット無くても動く。月額課金なし。
それだけのツールです。
