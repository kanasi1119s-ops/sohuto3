# 商品説明文案（BOOTH / Gumroad等向け）

## タイトル案

- オフライン見積・請求書メーカー｜データを外に出さない買い切りツール

## 説明文

個人事業主・小規模事業者向けの、見積書・請求書作成ツールです。

クラウド型の会計ソフトは便利な反面、「取引先の情報を外部のサーバーに預けたくない」「月額課金を
増やしたくない」という声もあります。本ツールは、そうした方のために作られました。

- **データは端末内だけ**：顧客情報・金額データは、あなたのブラウザの中にのみ保存されます。
  開発元を含め、外部のサーバーに送信されることはありません。
- **オフラインで動作**：インターネット接続がなくても、見積書・請求書の作成からPDF出力まで
  すべて利用できます。
- **買い切り**：月額課金ではなく、一度のお支払いでご利用いただけます（★価格は人間が設定）。
- **バックアップは自分の手で**：ワンクリックでJSON形式のバックアップを書き出し・読み込みできます。

### できること

- 顧客の登録・管理
- 見積書・請求書の作成、品目・数量・単価・税率からの自動計算
- PDF出力
- データのバックアップ書き出し・読み込み

### ご注意（購入前にご確認ください）

- 複数端末間の自動同期機能はありません（手動でのバックアップ移行は可能です）。
- PDF出力は現状、日本語の一部表示に制約があります（詳細はREADMEをご確認ください）。
- 動作にはモダンブラウザ（Chrome / Edge / Firefox 等の最新版）が必要です。
