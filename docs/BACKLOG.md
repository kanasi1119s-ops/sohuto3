# バックログ

## 今回のプロジェクト（offline-invoice-maker）の残タスク

- [ ] 数量・単価の負数バリデーション（低優先度、Round 2で発見）
- [ ] PDF出力への日本語フォント埋め込み（要フォントライセンス確認）
- [ ] 依存バンドルサイズの削減（jsPDFの未使用機能=html2canvas/dompurifyの動的import化など）
- [ ] 自動E2Eテストスイートの正式導入（本サイクルは手動Playwrightスモークのみ）
- [ ] 事業者情報・価格・EULA最終文言の確定（人間対応）

## 次サイクルで検討する新規プロジェクト候補

- **オフライン家計簿アプリ**（L1）: 個人向け、レシート手入力＋グラフ表示。需要は高いが競合も多く、
  差別化ポイント（例: レシートOCRのローカル実行）の検討が必要。
- **ローカル完結の議事録要約ツール**（L2、WebLLM/Ollama連携のBYOK方式）: 「録音データを外部に送りたくない」
  ニーズ。技術難易度がやや高いため2サイクル以上を想定。
- **CLI版の一括ファイルリネーム/整理ツール**（L3）: 実装難易度が低く1サイクルで完結しやすいが、
  類似の無料ツールが多く差別化が課題。

これらは未評価（本サイクルのスコアリングは実施していない）。次サイクルのPhase 0でスコアリングの上、
既存リポジトリとの重複がないか確認してから着手すること。
