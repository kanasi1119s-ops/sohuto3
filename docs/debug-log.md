## シミュレーション（5,000ゲーム、seed 1〜、`npm run sim -- 5000`）
| 構成 | 席0/1/2の勝率 | 平均得点 | ぴったり率 |
|---|---|---|---|
| 賢いAI×3 | 0.333 / 0.345 / 0.322 | 14.7 / 15.1 / 13.5 | 0.40 |
| ランダム×3 | 0.344 / 0.337 / 0.319 | −14.9 / −14.9 / −15.3 | 0.13 |
| 賢い(席0) vs ランダム×2 | 0.829 / 0.084 / 0.086 | 15.9 / −15.2 / −15.4 | 0.41 vs 0.12 |
| 賢い(席2) vs ランダム×2 | 0.090 / 0.090 / 0.820 | — | — |

- 全ゲームが必ず125アクション(5ラウンド×(入札3＋札21＋次へ1))で終了。無限ループなし。
- 席による有利不利: 後手(席2)がわずかに低い(0.322〜0.319)が、偏りは小さい。
- 技量の差が結果に出る（賢いAIが約82〜83%）＝運だけのゲームではないことの裏付け。
- 同点共同優勝: 約5.7%（賢いAI×3）。
- ほうき星の使用率は賢いAIで97%。**支配戦略かどうかは未検証**（人間による評価が必要）。
