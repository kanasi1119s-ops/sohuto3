## 持ち越し課題（軽微）

- 貪欲AIは「修理」「振り直し」をほとんど使わない（修理 平均0.05回/ゲーム）。人間が使う価値があるかは人間のテストプレイで要確認。
- 「やさしい」は貪欲AIで勝率95%、「むずかしい」は45%。人間の勝率は未計測。
- スクリーンリーダー対応は最低限（ボタンのラベル程度）。
- 実機（iPad・iPhone）での確認は未実施（Chromiumの幅エミュレーションのみ）。
