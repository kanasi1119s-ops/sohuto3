## シミュレーション結果（`npm run sim 3000`、シード固定）
詳細は [simulation-result.txt](simulation-result.txt)。
- 全ゲームが 36手（6ラウンド×6）ちょうどで終了。最大手数36。無限ループなし。
- CPU(greedy)対CPU(random)は98%以上でgreedyが勝つ → 選択に意味があり、ランダムでは勝てない。
- greedy同士: 先手46.8% / 後手52.0% / 引き分け1.2%。**やや後手有利**（約5ポイント差）。補正は未実施（持ち越し・人間のテストプレイで確認）。
- 各場所の使用率に極端な偏りなし（納品所は各8%台、注文所・屋台・一番どりが16〜17%）。
- 注意: ラウンド最後の手の平均選択肢が約2と少なく、一番どりが残り物になりがち（下記の持ち越し）。

## 持ち越し課題（軽微）
- 後手がやや有利（約5ポイント）。人間同士で偏りが出るか要確認。
- ラウンド最後の手番は選択肢が少ない。人間のテストプレイで「つまらない」と感じるか要確認。
- CPUは単純な評価値で動くため、強い人には物足りない可能性。
- 効果音・アニメーション・オンライン対戦は未実装。
- 面白さの判定はAIシミュレーションでは不可能。人間による実プレイが必要。
