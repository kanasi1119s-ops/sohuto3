## 各ラウンドの詳細

### ラウンド1: 初回テスト
- **ロジックテスト**: `test/logic.test.js` 実行時、テストコード側の2件の誤り（使用済みタイル判定テストの期待値が逆／存在しないB用タイルを重複指定）を発見。実装(`game.js`)ではなくテストの記述ミスであることを確認し、テストを修正。
- **シミュレーションによるバランス検証**: `node scripts/simulate.js 3000` を実行した結果、
  - random vs random: A 47.9% / B 52.1%（ほぼ互角）
  - **greedy vs greedy: A 30.9% / B 69.1%（著しい偏り）**
  - 追加調査で、貪欲AI同士では「全10ラインの(A合計−B合計)の総和（マージン）」が**常に厳密に0**になることを確認（2000/2000ゲームで検証）。そのため、ライン数が同数になった場合（37%程度）に既存のタイブレーク「マージンが同じなら後手Bが勝つ」が実質的に常に発火し、後手が不当に得をしていた。
  - **重大度: 高**（ゲームバランスの根幹に関わる設計不備のため、公開前に必ず修正すべき事項として扱った）。

### ラウンド2: 修正確認＋新規検出
- **修正内容**: `game.js` の `scoreState` を変更。ライン数・マージン合計が同値の場合、10本のラインを固定順（行1→行4→列1→列4→斜め1→斜め2）で走査し、最初にA/Bの合計が異なるラインの優位者を勝者とする処理を追加。全ラインが完全に同値という極端な場合のみ、最終フォールバックとして後手Bを勝者とする（発生頻度は理論上ごく稀）。
- **修正確認**: `node scripts/simulate.js 3000` を再実行し、greedy vs greedy が **A 49.7% / B 50.3%** まで改善したことを確認。random vs random は 49.0% / 51.0% で変化なし（想定通り、こちらは元々偏りが小さかった）。
- **新規問題**: なし。
- `docs/rules.md` とアプリ内ルール表示（`index.html`）のタイブレーク説明も実装と一致するよう同時更新。

### ラウンド3: 再テスト（回帰確認）＋最終判定
- **ロジックテスト再実行**: `node test/logic.test.js` → 9件全て成功。
- **シミュレーション再実行（5,000試行に増量）**:
  - random vs random: A 48.9% / B 51.1%
  - greedy vs greedy: A 49.6% / B 50.4%
  - greedy vs random: A 94.4% / B 5.6%（AIの強さの差が勝率に反映されており、支配戦略ではなく「読みの深さ」の差であることを確認）
  - random vs greedy: A 8.3% / B 91.7%（対称性も確認）
  - いずれのマッチアップも平均ターン数は常に16.00（min=max=16）で、ゲームが終わらない・手が詰まる不具合は一切発生しなかった。
- **UI/UXテスト（Playwright, Chromiumヘッドレス）**:
  - ルール画面の開閉が正しく動作する。
  - 「新しいゲーム」ボタンで盤面・手札が正しく初期化される。
  - 対戦相手をAI（ランダム／貪欲）に切り替えると、Bの手札タイルが正しく操作不可（disabled）になる。
  - 主要フロー「開始→手番操作→AI応答→終了→再戦」を自動操作で最後まで実行し、JSエラーゼロ・盤面16マス全て正しく埋まる・結果バナーとスコア表（10ライン分）が正しく表示されることを確認。
  - スマホ幅（375px, iPhone SE相当）で横スクロールが発生しないことを確認。
- **重大バグ（クラッシュ、進行不能、勝敗の誤判定、終わらないゲーム）**: ゼロ。

## 既知の軽微な課題（持ち越し）

- 4x4・完全公開情報という小規模設計のため、理論上は深い読み（多手先の完全探索）を行えば最善手が解析され得る。MVPの貪欲AI（1手先読み）はそこまでの強さはなく、人間同士の対戦では十分な読み合いが発生する見込みだが、厳密な「解の有無・先手必勝/後手必勝の判定」はゲーム理論的な全探索（16!オーダーの探索）を要するため本サイクルでは未実施。次サイクル以降、時間があれば全探索または強めのAI（数手先読みのミニマックス等）での検証を推奨。
- AIの「思考時間」は演出上300msの固定ディレイのみで、実際の計算時間ではない（貪欲AIの計算自体は数ms未満で完了する）。
- オンライン対戦・アカウント機能はMVPスコープ外（意図的な未実装）。
