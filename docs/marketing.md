# マーケティング素材（Sales-Writer フェーズ）

## ストアページ / LP用コピー

### キャッチコピー
**「置くたびに、奪い合う。」**

### 30秒で分かるゲーム紹介
盤面は5×5マス。あなたと相手は、1から9までの数字タイルを1枚ずつ交互に置いていきます。隣に置いたタイルより数字が小さい相手のタイルは、そのまま奪えます。運の要素は一切なし、最大18手で決着する短時間の頭脳戦。先手が強すぎる初手を打つと、後手は「スワップ」でその手を丸ごと奪い返せます。さあ、盤面のどこに、どの数字を置きますか？

### 基本情報
- プレイ人数: 2人（1台の画面で交互プレイ／AI対戦可）
- プレイ時間: 約10〜15分
- 対象年齢: 8歳以上
- 価格: 無料（投げ銭歓迎）※方針は運営判断待ち

### 特徴3点
1. **運要素ゼロの完全情報ゲーム** — サイコロもカード運もなし。読み合いだけで勝敗が決まります。
2. **最大18手で必ず決着** — 長考しても大味にならない、テンポの良い短時間対戦。
3. **先手有利を打ち消す「スワップ」ルール** — 初心者同士でも大きく偏らない設計を目指しました。

### スクリーンショットの撮影指示
1. ゲーム開始直後の盤面（空の5×5マスと両者の手札が見える構図）
2. 中盤、複数のタイルが奪い合われて盤面に色が入り乱れている場面
3. 終了時の結果パネル（勝敗表示）
4. スマートフォン縦画面での表示（レスポンシブ対応が伝わるもの）

## ルールの3行まとめ
1. 5×5マスに1〜9の数字タイルを交互に置く。
2. 置いた数字より小さい隣のタイルは奪える（同数・大きい数字は奪えない）。
3. 18手で終了、マスを多く支配した方が勝ち（同数ならタイルの合計値で判定）。

## はじめての人向けチュートリアル文
「はじめまして。このゲームにサイコロもカードの引きもありません。全部、あなたと相手の『置き方』だけで決まります。まずは好きな数字を1枚、盤の真ん中あたりに置いてみましょう。相手がその数字より大きい数字を隣に置くと、あなたのタイルは奪われてしまいます。だから、強い数字は温存して、終盤の奪い合いに備えるのもひとつの作戦です。18手、あっという間に決着します。まずは1局、気軽に遊んでみてください。」
