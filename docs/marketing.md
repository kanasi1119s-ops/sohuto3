# マーケ素材（そのまま使える草稿）

## キャッチコピー
- 「嵐の予報を読んで、サイコロで船を守れ。」
- 「夜明けまでに、あかりを港へ。」

## 30秒紹介
嵐の夜、あなたは灯台守。4そうの船を、サイコロの出目で港へ導きます。毎晩の嵐は先に見えるから、「進める？ 守る？ 直す？」をみんなで相談。8晩のうちに3そうを港へ届けられたら勝ちです。ブラウザですぐ遊べて、1人でも遊べます。

- 1〜4人（協力）／ 約15分 ／ 8歳以上 ／ 無料・登録なし

## 特徴3点
1. 嵐が先に見える：予報を見て作戦を立てられる。
2. 1つのサイコロの使い道が3つ：進む／錨で守る／修理（出目によって使えるものが変わる）。
3. 3段階の難しさ：やさしい／ふつう／むずかしい（4そう全員が目標）。

## 3行まとめ
1. 毎晩、嵐の予報を見て、サイコロを振る。
2. 出目を使って船を進める・錨で守る・修理する。
3. 8晩のうちに3そう（むずかしいは4そう）を港へ。2そう沈んだら負け。

## はじめての人向けチュートリアル
最初は「やさしい」で。①今夜の嵐を読む ②低い出目（1〜3）は嵐を受ける船に錨 ③高い出目は船を進める ④船の横の「嵐のあと」で結果を確かめて「ラウンド終了」。困ったら「ヒント」と「ひとつ戻す」が使えます。

## SNS告知文
**ボードゲーム好き向け**
協力ダイスゲーム「灯台守のよあけ」を作りました。嵐カードは行動の前に公開、出目は進む／錨／修理に割り当て。大渦で先頭の船が戻されるので、突っ走りすぎ注意。ブラウザで無料。 #ボードゲーム #ソロプレイ

**ライト層向け**
灯台守になって、嵐の夜に船を港へ導こう。1人でも家族でも遊べる約15分のゲーム。インストール不要、ブラウザですぐ遊べます。

**ひとこと**
夜明けまでに3そうを港へ。あなたは何そう届けられる？
