## 実装内容

- リポジトリ: `kanasi1119s-ops/sohuto3`（**Public** — 上記⚠参照。本来は指示書に従いprivateで新規作成すべきでしたが、リポジトリ自体の作成・可視性変更を行う権限がこのセッションになく、既存の状態のまま利用しました）
