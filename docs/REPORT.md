## マーケットリサーチ結果サマリ

GitHubアクセスが単一リポジトリに制限されていたため、Web検索エージェント等を用いた広範な市場調査
フェーズは簡略化し、運用指示書に明記されている「クラウドに預けたくない」「サブスクではなく買い切りが
いい」というニーズ（プライバシー重視・オフライン需要）を直接の出発点として企画した。

**採用案: オフライン見積・請求書メーカー**
- 需要: 個人事業主・フリーランス向けの見積書・請求書作成は定番ニーズ。クラウド会計SaaSの月額課金や
  データ預託に抵抗があるユーザー層が一定数存在する。
- 実装難易度: 低〜中（静的SPA、IndexedDB、PDF生成のみで完結、サーバー不要）。1サイクルでMVPまで
  到達可能と判断。
- 法的リスク: 低（スクレイピングなし、第三者コンテンツなし、個人情報は端末内保存のみ）。
- 差別化: 「データが外部に一切出ない」「オフライン動作」を実装レベルで保証し、テストで裏付けている点。
- 運用コスト: 極めて低い（静的ファイル配布のみ、サーバー運用不要）。

正式な25点満点スコアリング・複数案の比較検討は、市場調査フェーズを簡略化した都合上、今回は実施して
いない。次サイクルでGitHubアクセス範囲が拡大された場合は、指示書どおりのスコアリングを行うこと。
