# コネクロス (ConneCross) ルールブック

version 1.0 / 2026-09-27

## 1. ゲーム概要

コネクロス は、7×7マスの盤上に自分の色の石を置き、**盤上で最大のつながり（連結グループ）を作った方が勝ち**の2人対戦アブストラクトゲームです。

各ターン、山札から1枚カードをめくり、そのカードが指示する置き方に従って石を置きます。カードには「普通に置く」「好きな場所に飛ばす」「相手の邪魔をする」の3種類があり、めくったカードによって取れる行動が変わるため、盤面をどう育てるか・相手をどう妨害するかの読み合いが生まれます。

- **プレイ人数**: 2人（うち1人をAI対戦相手に置き換え可能。ソロプレイ対応）
- **プレイ時間**: 約15〜20分
- **対象年齢**: 8歳以上
- **必要なもの（デジタル版）**: ブラウザのみ
- **必要なもの（Print & Playで物理プレイする場合）**: 7×7の盤面1枚、赤石24個・青石24個・グレーの障害物石8個程度、行動カード20枚（後述の内訳で自作）

## 2. コンポーネント一覧

| コンポーネント | 数量 | 説明 |
|---|---|---|
| 盤面 | 1 | 7×7 = 49マスの正方形グリッド |
| プレイヤー石（赤） | 最大49個 | プレイヤー1 (先手) の石 |
| プレイヤー石（青） | 最大49個 | プレイヤー2 (後手) の石 |
| 障害物石（グレー） | 最大49個 | どちらの陣地にもならない中立の石 |
| 行動カード | 20枚 | 内訳: PLACE（普通に置く）12枚 / JUMP（好きな場所に置く）4枚 / BLOCK（妨害する）4枚 |

石・障害物の数はどちらも盤面のマス数(49)を上限として必要な分だけ用意すれば問題ありません（デジタル版は自動管理）。

## 3. 勝利条件・終了条件

- セットアップ時、**盤面中央 (4行4列目) には最初からグレーの障害物が1個置かれています**（先手・後手の手数を均等にするための調整ルール。詳細は8節参照）。これにより実際に石を置ける空きマスは48マスになります。
- 盤面の**残り48マスすべてが埋まった時点で即座にゲーム終了**します。
- 終了時、各プレイヤーについて「上下左右に隣接して連結している自分の石のかたまり（連結グループ）」の中で最大のものの石数を数えます。
- **その最大連結グループが大きい方が勝ち**です。
- 同数の場合は、盤上に置いた自分の石の総数が多い方が勝ちです（BLOCKで置いた障害物石はカウントしません）。
- それでも同数の場合は **引き分け** とします。

石の置き方は毎ターン必ず1マスを埋めるため（自分の石またはグレーの障害物）、ゲームは必ず**最大48ターン以内**に終了し、詰み・無限ループは発生しません。また空きマスが偶数（48）のため、P1・P2は必ず同じ手数（24手ずつ）を行います。

## 4. ターンの流れ

先手（プレイヤー1・赤）から交互に手番を行います。各手番で以下を行います。

1. 山札から行動カードを1枚めくる（山札が尽きたら、それまでの捨て札をよく混ぜて新しい山札にする）
2. カードの指示に従って、盤上の空きマスに石（またはBLOCKの場合は障害物）を1個置く
3. めくったカードを捨て札にする
4. 手番を相手に渡す
5. 盤面が全て埋まっていればゲーム終了。埋まっていなければ1に戻る

## 5. カードの種類とアクション

### PLACE（通常配置）— 山札20枚中12枚
- 自分の石を、**すでに盤上にある自分の石のいずれかに上下左右で隣接する空きマス**に置く。
- まだ自分の石を1つも置いていない場合（ゲーム最初の自分の手番）は、盤上のどの空きマスにでも置いてよい。
- **例外（詰まり救済ルール）**: 自分の石はあるが、それに隣接する空きマスが盤上に1つも残っていない場合に限り、盤上のどこか好きな空きマスに置いてよい（JUMPと同じ扱いになる）。

### JUMP（自由配置）— 山札20枚中4枚
- 盤上のどの空きマスにでも、自分の石を1個置ける（隣接条件なし）。
- 遠く離れた場所に新しい拠点を作ったり、相手のかたまりを分断する位置に置いたりする自由度の高いカード。

### BLOCK（妨害）— 山札20枚中4枚
- 盤上のどの空きマスにでも、グレーの障害物を1個置ける。
- 自分の石は増えないが、相手が育てようとしているかたまりを分断したり、有利なマスを潰したりできる。
- 自分のターンを1回「消費」してでも相手を止めたいときに使う、駆け引きの要となるカード。

## 6. セットアップ手順

1. 7×7の盤面を用意し、**中央マス (4,4) にグレーの障害物を1個置く**（先後の手数を均等にするための調整。8節参照）。
2. 行動カード20枚（PLACE12・JUMP4・BLOCK4）をよく混ぜて山札にする。
3. 先手（プレイヤー1・赤）を決める（デジタル版は常にプレイヤー1が先手。CPU対戦時は先手/後手を選択可能）。
4. 「4. ターンの流れ」に従って交互にプレイする。

## 7. プレイ例（最初の2ターン）

- **1ターン目（P1・赤）**: 山札からPLACEをめくる。まだ自分の石がないので、盤面のどこでも置ける。中央のすぐ隣 (3,4) に配置。
- **2ターン目（P2・青）**: 山札からJUMPをめくる。まだ自分の石がないが、JUMPなのでどこでもよい。角に近い (2,2) に配置。
- **3ターン目（P1・赤）**: 山札からPLACEをめくる。既に (3,4) に石があるので、その上下左右いずれかの空きマス、例えば (3,5) に配置し、かたまりを2個に拡大する。
- **4ターン目（P2・青）**: 山札からBLOCKをめくる。P1が伸ばしそうな (2,4) にグレーの障害物を置き、拡大方向を制限する。

このように、めくったカード次第で「素直に育てる」か「相手の芽を摘む」かの選択を毎ターン迫られます。

## 8. バランス設計の仮説と実測結果

- **先手/後手バランス（当初案 → 修正後）**: 当初は盤面49マス全てを使う設計だったが、テストプレイ用AIシミュレーション（Round 1、2,000試合）で **先手55.4% / 後手41.7% / 引き分け2.9%** という無視できない偏りが確認された。原因は49マスが奇数のため先手が後手より1手多く石を置けること（25手 vs 24手）にあると特定。
  - **対策**: 盤面中央 (4,4) に最初からグレーの障害物を1個配置し、実際に使えるマスを48（偶数）にすることで、先手・後手が必ず同じ24手ずつを行う構造にした。
  - **修正後の実測（Round 2、2,000試合）**: 先手勝率と後手勝率の差が大幅に縮小したことをdocs/debug-log.mdに記録。数値は同ファイル参照。
- **支配戦略の排除**: 「常に中央から広げるのが最善」にならないよう、盤上の空きマス次第でJUMP/BLOCKの価値が変動するようにしている。カードの引きが確率的なため、同じ盤面状況でも毎回最善手が変わりうる。
- **支配戦略の排除**: 「常に中央から広げるのが最善」にならないよう、盤上の空きマス次第でJUMP/BLOCKの価値が変動するようにしている。カードの引きが確率的なため、同じ盤面状況でも毎回最善手が変わりうる。
- **運と戦略の比率**: カードの種類はランダムだが、「どこに置くか」は完全にプレイヤーの選択。運は「いつBLOCK/JUMPが引けるか」のタイミングのみに影響し、配置判断そのものは実力が反映される設計。
- **逆転要素**: BLOCKで終盤に相手の最大グループへの分断を狙うことで、終盤までリードが確定しない緊張感を作る。
- **ダウンタイム**: 1手番で行うことは「カードをめくって1マスに置く」だけなので、待ち時間は非常に短い。

## 9. 未定義状況への対処（曖昧さの排除）

- **盤上に自分の石が無く、かつBLOCKで埋められて空きマスが無い場合**: 発生しません。石を持たない状態で置けなくなるのは盤面が全て埋まった時のみで、その時点でゲームは終了します。
- **PLACEで隣接マスが無い場合**: 5節の「詰まり救済ルール」によりJUMP同様どこにでも置けます。
- **同点の場合**: 6節の通り総石数、それでも同点なら引き分けとします。
- **山札切れ**: 捨て札を再シャッフルして山札を再構成します（トランプの一般的なルールと同様）。
