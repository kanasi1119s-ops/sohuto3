# LinkForge（リンクフォージ）ルールブック

対象年齢: 8歳以上　プレイ人数: 2人　プレイ時間: 5〜15分

## 1. コアループ

> 空いているマスに自分の石を置くか、限られた回数だけ相手の石を奪って置き直す「フォージ」を使い、先に自分の石を5つ連結させる。

## 2. コンポーネント

- 盤面: 7×7 マス（49マス）
- 石: 赤（先手 / プレイヤーA）・青（後手 / プレイヤーB）各24個相当（デジタル版では無制限に生成されるため物理個数の制約はない）
- フォージ権: 各プレイヤー3回（ゲーム開始時に付与、消費のみで補充されない）

## 3. セットアップ

1. 盤面（7×7の空マス）を用意する。
2. 先手（プレイヤーA / 赤）と後手（プレイヤーB / 青）を決める。
3. 各プレイヤーのフォージ権を3回にセットする。
4. 先手から手番を開始する。

## 4. 先手番の特別ルール：パイルール（オープニング・スワップ）

五目並べ系ゲームは先手が有利になりやすいため、以下の補正を行う。

1. プレイヤーAは最初の手番で、通常の「配置」のみを行える（フォージは使用不可）。
2. プレイヤーAが石を置いた直後、プレイヤーBは次のいずれかを選択する。
   - **スワップ**: Aが置いた石の色を青（B）に変更する。その後、手番はAに移り、Aは新たに青ではない側（＝これ以降Aは新しい石を置くたびに元の後手側の色を使う想定ではなく、実装上は「Aが次の手番から石を置く」形で進行し、最初に置かれた1個の石だけがBの色になる）。
   - **続行**: スワップせず、Bが通常どおり自分の色（青）で石を配置する。以降は通常の交互手番。
3. スワップは一度きり（最初の1手に対してのみ）。

これにより「強すぎる初手」を後手が选択的に無効化でき、先手有利を緩和する。

## 5. ターンの流れ

手番プレイヤーは、以下の**いずれか1つ**を必ず行う。

### (a) 配置（Place）
- 空いている任意のマスに自分の石を1個置く。

### (b) フォージ（Forge）※フォージ権が1回以上残っている場合のみ
1. 相手の石のうち、次の**両方**の条件を満たす石を1個選び、盤上から取り除く。
   - 同色で4方向隣接の連結グループが**3個未満**であること（保護されていない）
   - 置かれてから**2ターン以上経過**していること（置かれた直後の1ターンは猶予期間としてフォージ対象にならない）
2. 空いている任意のマス（取り除いたマス自身でもよい）に自分の石を1個置く。
3. フォージ権を1回消費する。

> **猶予期間について**: QAのシミュレーションテストで、猶予期間なしだと「開いた三（両端が空きマスの3連結）を単独の石でブロックしても、相手がその場でフォージして即座にブロックを取り消し、そのまま5連結を完成させてしまう」という、先手が実質的に無条件で勝ててしまう致命的な必勝パターンが見つかった。これを防ぐため、置かれたばかりの石には1ターンの猶予期間を設けている（詳細は `docs/debug-log.md` のラウンド1参照）。

配置・フォージのいずれの場合も、石を置いた直後に勝利判定を行う。

## 6. 勝利条件

- 自分の石が縦・横・斜めいずれかの方向に**連続して5個**並んだ時点で、その手を打ったプレイヤーが即座に勝利する。
- 石を置いた結果、両プレイヤーが同時に5連結になることは、直前の手番プレイヤーの石のみを判定するため発生しない。

## 7. 終了条件（引き分け回避・有限性の保証）

- 盤面49マスがすべて埋まり、かつ勝者が確定していない場合、**盤上の最大連結グループの大きさ**を比較する。
  - 大きい方が勝利。
  - 同数の場合は**盤上の総石数が多い方**が勝利（フォージの使用状況により差が出ることがある）。
  - それでも同数の場合は**引き分け**とする。
- ゲームの有限性は以下の理由で保証される。
  - 「配置」は必ず空きマスを1つ減らす。盤面49マスを完全に埋めるには、スワップの有無によらず必ず49回の「配置」が必要になる。
  - 「フォージ」は空きマスの総数を変化させない（相手の石を1個除去し、自分の石を1個置くため）が、フォージ権は各プレイヤー3回、合計最大6回までしか使用できない。
  - 「スワップ」は開幕直後に最大1回だけ発生し得る、配置を伴わない特殊な1手である。
  - したがって、ゲームは最大 49（配置）+ 6（両者のフォージ権合計）+ 1（開幕スワップ）= **56手以内**に必ず終了する。

## 8. 例外・タイブレーク処理まとめ

| 状況 | 処理 |
|---|---|
| フォージ対象にできる石がない（相手の石がすべて3連結以上のグループに属す） | フォージは選択不可。配置のみ行える |
| 空きマスがない状態でフォージしようとする | 発生しない（空きマスがなくなる前に終了条件で試合が終わっているため） |
| 盤面が埋まり両者の最大連結が同数 | 総石数が多い方が勝利。総石数も同数なら引き分け |
| パイルールでBがスワップを選択 | Aが置いた石は青（B）の石になる。手番はAに戻り、以降通常進行 |

## 9. プレイ例（冒頭2ターン）

1. プレイヤーA（赤）が中央マス（4,4）に石を配置。
2. プレイヤーBは「続行」を選択（中央を奪うにはリスクがあると判断）。プレイヤーBは(4,5)に青石を配置。
3. 以降、AとBが交互に「配置」または「フォージ」を選びながら、5連結を目指す。

## 10. バランス設計の仮説

- **先手/後手バランス**: パイルールにより、先手が強すぎる初手を打った場合は後手がスワップして相殺できる。QAフェーズのAIシミュレーションで先手勝率を計測し、50%±10pt程度に収まるかを検証する。
- **支配戦略の抑制**: フォージは「3連結未満の石」しか対象にできないため、序盤の布石を壊す牽制手段にはなるが、終盤の完成間近のグループは安全というトレードオフがあり、単純な「常に配置だけが最善」という支配戦略になりにくい設計を狙っている。
- **運と戦略の比率**: 完全確定情報・非乱数ゲーム（AIの思考にのみ乱数要素を使う）。運要素はゼロで、純粋に読み合いと配置判断が勝敗を分ける。
- **逆転要素**: フォージ権を終盤まで温存し、相手の弱い石を刈り取って一気に自分の連結を伸ばす「終盤の逆転札」として機能する想定。
- **ダウンタイム**: 1手あたりの意思決定はシンプル（配置マス、またはフォージの対象+配置先）なため、待ち時間は短い想定。
