# カラーフィールド (Color Field) ルールブック

対応人数: 2人（同一端末での対面プレイ、または一方をAIに任せるプレイが可能）
プレイ時間の目安: 5〜10分
対象年齢: 8歳以上（暴力・グロテスク表現なし）

## 1行コンセプト
交互に自分の色のマスを隣接拡張しながら陣地を育て、盤面が埋まったときに
「自分の色でひとつながりになっている最大のかたまり」が大きい方が勝つ、
シンプルな陣地拡張アブストラクトゲームです。

## コンポーネント一覧
- 盤面: 7×7マス（49マス）の正方グリッド
- プレイヤー駒: アンバー（先手・オレンジ）／アジュール（後手・青）の2色。
  各色とも盤面のマス数を上限に何個でも使える（物理的な個数制限はない）
- サージトークン: 各プレイヤー3個ずつ（後述の特殊配置に使用）

## セットアップ
1. 盤面を空の状態にする。
2. 先手（アンバー）が左上3×3マス、後手（アジュール）が右下3×3マスを
  それぞれ「スタートゾーン」とする。
3. 先手から交互に手番を行う。

## 手番でできること
自分の手番では、以下のいずれか1つを行う。

1. **通常配置**: 空いているマスのうち、
   - まだ自分の色を1つも置いていない場合は、自分のスタートゾーン内の
     好きな空きマスに置く。
   - すでに自分の色を置いている場合は、自分の色のマスに隣接する
     （上下左右のいずれか）空きマスに置く。
2. **サージ配置**: サージトークンを1個消費して、盤面上のどの空きマス
   （隣接条件を無視してよい）にも自分の色を置く。孤立した拠点を作って
   新しい陣地を育てたり、相手の広がりを分断したりするのに使う。
   サージトークンは1ゲームにつき3個までしか使えない。
3. **パス**: 上記のどちらの方法でも置けるマスが1つも無い場合に限り、
   手番をパスする。置けるマスがある限りパスはできない（強制着手）。

## 終了条件
- 盤面の49マスがすべて埋まったとき、ただちにゲーム終了。
- 両プレイヤーが連続でパスしたとき（＝どちらも打てるマスがない）、
  ただちにゲーム終了。
- 盤面は49マスと有限で、置ける場所は手番ごとに単調に減っていくため、
  ゲームは必ず有限回の手数で終了する（無限ループにはならない）。

## 勝敗判定
ゲーム終了時、各プレイヤーについて「自分の色のマスが上下左右に
連結している最大のかたまり（連結成分）のマス数」を数える。

1. 最大のかたまりが大きい方が勝ち。
2. 同数の場合は、盤上に置いた自分の色の総マス数が多い方が勝ち。
3. それでも同数の場合は、2番目に大きいかたまりが大きい方が勝ち。
4. すべて同じ場合は引き分け。

## タイブレーク・例外処理まとめ
| 状況 | 処理 |
|---|---|
| 置けるマスが無い | 強制的にパス（自分から任意でパスすることはできない） |
| 両者連続パス | ゲーム終了、その時点で勝敗判定 |
| サージトークンを使い切った | それ以降はサージ配置を選べない（通常配置とパスのみ） |
| 最大連結成分が同数 | 総マス数→2番目に大きい連結成分の順で比較 |
| すべて同数 | 引き分け |

## セットアップ〜1〜2ターンのプレイ例
1. アンバー（先手）が左上スタートゾーン内の (0,0) に配置。
2. アジュール（後手）が右下スタートゾーン内の (6,6) に配置。
3. アンバーが (0,0) に隣接する (0,1) に配置し、陣地を伸ばす。
4. アジュールが (6,6) に隣接する (5,6) に配置。
5. …これを繰り返し、盤面が埋まるかパスが連続したら終了し、
   それぞれの最大連結かたまりの大きさを比較して勝者を決める。

## バランス設計の狙いと既知の課題（次サイクルへの申し送り）
- **狙い**: 隣接拡張のみだと「壁で相手を囲んで動けなくする」駆け引きが生まれ、
  サージトークンは追い詰められたときの逆転・分断の切り札として機能する
  ことを狙っている。
- **既知の課題（重要）**: 社内シミュレーション（AI同士の自動対戦）で、
  互いに最適化する貪欲AI同士では**先手が約83%勝利**する強い先手有利が
  確認されている。一方、実力が拮抗している場合の目安となるランダムAI
  同士では先手56%程度に収まっており、先手有利の大きさはプレイヤーの
  「相手を囲い込むブロック精度」に強く依存することが分かっている。
  詳細は `docs/debug-log.md` を参照。人間同士のテストプレイでの体感バランス
  確認と、次サイクルでの調整（スタートゾーンの形状変更、隣接以外の
  成長経路の追加、先手のみ初手を1マス限定にする、など）を推奨する。
