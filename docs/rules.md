# みなとのあさいち 遊び方

> 人数: 2人（CPU対戦で1人でもOK） ／ 時間: 約10〜15分 ／ 対象: 8歳以上

## ひとことで言うと

朝の港の市場で、**ワーカー（働き手）を置いて材料を集め、お客さんの「注文」を納品して点数をかせぐ**ゲームです。同じ場所には1人しかワーカーを置けないので、相手に先に取られる前に、どこへ行くかが勝負です。

## ルールは3行

1. 交代でワーカーを1人ずつ、市場の「場所」に置く。置いたらすぐその場所の効果が起きる。
2. 魚・野菜・米を集めて、注文カードを**納品所**で納品すると得点。
3. 6ラウンド（ワーカー各3人ずつ）あそんで、点数が多い方の勝ち。

## 用意するもの

| もの | 内容 |
|---|---|
| ワーカー | 各プレイヤー3人（毎ラウンド全員使います） |
| 資源 | 🐟魚・🥬野菜・🍚米の3種類。各種類6個まで持てます |
| 注文カード | 全20枚。「必要な資源」と「点数」が書かれています |
| 場所 | 8か所。1か所にワーカー1人まで |

## ゲームの流れ

ゲームは**6ラウンド**です。1ラウンドは次の流れです。

1. **先手から交代で**、ワーカーを1人ずつ置きます（ぜんぶで6回。先手→後手→先手→後手→先手→後手）。
2. 置いた場所の効果は**その場でただちに**起きます。
3. 6回置き終わったらラウンド終了。ワーカーは全員もどり、場所もあきます。
4. 次のラウンドの先手が決まります（下の「一番どり」参照）。何もなければ先手と後手が入れかわります。
5. 場に出ている注文カードのうち一番古い1枚が、新しいカードに入れかわります。

第6ラウンドが終わったらゲーム終了、得点計算です。

## 8つの場所

| 場所 | 効果 |
|---|---|
| ⚓ 漁港 | 🐟魚を3つもらう |
| 🌾 畑 | 🥬野菜を3つもらう |
| 🏚️ 米蔵 | 🍚米を3つもらう |
| 🏮 朝市の屋台 | 魚・野菜・米を1つずつもらう |
| 📜 注文所 | 場に出ている注文カードを1枚えらんで手元に加える（そのあと場に新しいカードが出ます） |
| 📦 納品所A・B | 手元の注文カードを1枚えらび、書かれた資源をはらって**納品**。カードの点数が入ります |
| 🐓 一番どり | 好きな資源を1つもらう。さらに**次のラウンドの先手**になる |

### 置けない場所について

- 資源がもう6個で1つも増えない場所には置けません。
- 注文所は、手元に注文カードが3枚あるときは使えません。
- 納品所は、はらえる注文カードがあるときだけ使えます。
- どこにも置けないときだけ、そのワーカーは**パス**になります。

### 資源の上限

資源は種類ごとに**6個まで**です。それ以上はもらえません（あふれた分は消えます）。

## 注文カード

カードには次のことが書かれています。

- **料理の名前**と**種類**（海＝魚が多い／山＝野菜が多い／里＝米が多い）
- **必要な資源**（例: 🐟3 🍚1）
- **点数**

納品すると、必要な資源をぜんぶはらって、そのカードは自分の「納品済み」になります。

## 得点計算

ゲーム終了時、次を足し算します。

- 納品済みカードの点数の合計
- **三種そろいボーナス +4点**: 海・山・里の3種類を1枚ずつ以上、納品している
- **同じ種類ボーナス +3点**: 同じ種類を3枚以上、納品している
- **残念マイナス −1点**: 手元に納品しきれなかった注文カード1枚につき

三種そろいボーナスと同じ種類ボーナスは、両方もらえることもあります。

### 同点のとき

1. 納品した枚数が多い方の勝ち
2. それも同じなら、残っている資源の合計が多い方の勝ち
3. それも同じなら引き分け

## セットアップ

1. 注文カードをよくまぜて、場に3枚ならべます（残りは山札）。
2. 資源は2人ともゼロからスタートします。
3. プレイヤー1が最初のラウンドの先手です。

## プレイ例（第1ラウンド）

1. 先手が **⚓漁港** → 魚3つ。
2. 後手が **📜注文所** で「さしみ定食（🐟3）」を取る。
3. 先手が **📜注文所** に行きたいが後手に取られた。かわりに **🏮屋台** → 魚4・野菜1・米1。
4. 後手が **🐓一番どり** → 好きな資源1つ＋次のラウンドの先手に。
5. 先手が **🌾畑**、後手が **🏚️米蔵**。…これで6回おわり。
6. 次のラウンドは後手（一番どりの人）が先手で始まります。

## 画面の操作方法

- **ホーム画面**で、CPU対戦かふたり対戦（1台を交代で使う）を選び、「はじめる」を押します。
- ゲーム画面の**場所のカード**をタップ（クリック）すると、そこにワーカーを置きます。
- 注文カードや資源を選ぶ必要があるときは、選ぶ画面が出ます。
- 置けない場所は薄く表示されます。いま置ける場所は光ります。
- 「ひとつ戻す」で、ふたり対戦のときだけ直前の操作を取り消せます。
- 「ルール」ボタンで、いつでもこの説明書が読めます。

## よくある質問（FAQ）

**Q. 納品したい注文が場にあるのに、手元にないと納品できませんか？**
A. はい。先に📜注文所で手元に加える必要があります。

**Q. 同じラウンドで、同じ人が納品所AとBの両方に置けますか？**
A. はい、置けます。ワーカーは3人いるので、使いみちは自由です。

**Q. 一番どりを取ったのにゲーム終了ラウンドだった場合は？**
A. 最終ラウンドの「次のラウンド」はないので、先手の効果はありません（資源1つだけもらえます）。

**Q. 山札がなくなったら？**
A. 新しいカードは出ません。場のカードが減っていきます。

**Q. 先手と後手で有利不利はありますか？**
A. CPU同士の1000回以上の対戦では、先手の勝率が46〜47%、後手が52%ほどで、ほぼ互角です。

## バランス設計のメモ（作者向け）

- ワーカーが少なく場所が多いので、「いつ何を取るか」より「何を取られたくないか」の読み合いが生まれます。
- 資源の上限と手札の上限があるので、一つの戦略（たとえば注文をため込むだけ）は強くなりません。
- 運は注文カードの並びだけです。ダイスはありません。
